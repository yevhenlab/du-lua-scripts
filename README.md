# Dual Universe Lua Scripts

A collection of Lua scripts for Dual Universe.

## Scripts

| Project | Description |
| --- | --- |
| [Display Linked Industry Product on Screen](<Display Linked Industry Product on Screen/>) | Shows each linked industry unit's current product and details on its paired screen. |
| [Linked Hub Production Screen](<Linked hubs placed near screen shows info/>) | Projects nearby hubs onto a Screen grid and displays Industry and container products. |
